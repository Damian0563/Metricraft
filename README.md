# Metricraft

Analytics platform for log observability, oriented on visuals and reporting.

## Features

- Log observability and monitoring
- Visual dashboards and charts
- Reporting tools
- Real-time data analysis

## Tech Stack

- **Framework**: Nuxt 4
- **UI**: Vue 3
- **Styling**: Tailwind CSS 4
